# 🔌 Bhavya's MCP Nexus

Model Context Protocol (MCP) tool registry and JSON-RPC connector for plugging external tools, databases, and filesystem access into AI models.

---

## 📂 File & Folder Structure — Direct Edit Guide

| File / Folder | What It Does | When to Edit |
| :--- | :--- | :--- |
| `index.html` | MCP server list & tool schema inspector | Edit tool registry catalog, connection cards, and status pills |
| `style.css` | Server status cards & JSON schema viewer styles| Adjust connector badges, latency counters, and modal sheets |
| `app.js` | MCP protocol message handshake & invocation | Register new MCP tools, modify JSON-RPC payloads, and test calls |
